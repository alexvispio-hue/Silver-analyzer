# Публикация версии с реальными данными

Приложение требует постоянно доступный Node.js backend: он загружает данные,
рассчитывает сигналы, хранит историю и раздаёт React frontend. GitHub Pages
не запускает такой backend. Синтетическая Pages-сборка удалена.

## Render

[Запустить подготовленную конфигурацию на Render](https://render.com/deploy?repo=https://github.com/alexvispio-hue/Silver-analyzer/tree/codex/real-market-data).
Ссылка использует ветку с исправлениями и заполняет параметры из render.yaml.
Публикация начинается после подтверждения конфигурации в вашем аккаунте Render.
Автоматическое развёртывание по каждому push выключено; обновления запускаются вручную.

В репозитории есть render.yaml. Конфигурация запускается без обязательных ключей:
FRED берётся из публичных CSV, новости — Yahoo Finance RSS.

1. Загрузить проверенные изменения в GitHub.
2. В Render выбрать New → Blueprint и подключить репозиторий Silver-analyzer.
3. Выбрать ветку с исправлениями и render.yaml.
4. Проверить бесплатный план и условия сервиса перед созданием.
5. После успешного deploy открыть выданный адрес и /api/health.
6. Проверить источник/время котировки, графики, реальные новости, FRED и WebSocket /ws.
7. Добавить подтверждённый публичный URL в About репозитория и в резюме.

Команды сборки и запуска:

```sh
npm ci --prefix backend --omit=dev && npm ci --prefix frontend --include=dev && npm run build
npm start
```

Переменные:
- NODE_VERSION=22
- NODE_ENV=production
- NEWS_PROVIDER=yahoo
- DB_PATH=/tmp/silver-analyzer/data.db
- PORT назначается хостингом
- FRED_API_KEY — необязательно: добавить через секреты сервиса для FRED API
- NEWS_API_KEY — только при выборе NEWS_PROVIDER=newsapi и подходящем плане NewsAPI

Не помещать API-ключи в GitHub, frontend, VITE_* или публичные файлы.

## Ограничения бесплатного хостинга

Бесплатный Render засыпает после 15 минут без входящих запросов; пробуждение может
занять около минуты. SQLite в /tmp теряется при перезапуске, засыпании и redeploy.
Для постоянной истории нужен платный persistent disk с DB_PATH под его mount path
или внешняя БД. Без постоянной работы сервера часть 24/72-часовых результатов
останется неизвестной; пропуски не подменяются сегодняшней ценой.

[Render Free](https://render.com/docs/free) · [Persistent disks](https://render.com/docs/disks)

## Источники и данные

- Основная spot-котировка — GoldPrice; резервная — Yahoo Finance SI=F.
- Графики/индикаторы — реальные свечи SI=F. Spot XAGUSD и futures SI=F различаются:
  интерфейс показывает это явно. Для строгого spot-продукта нужен источник
  истории XAGUSD, который разрешает серверное использование.
- FRED показывает последние опубликованные периоды, с датой и ссылкой на серию;
  API при недоступности переключается на публичный CSV.
- Yahoo RSS показывает заголовок, ссылку и настоящее время публикации.
- Бесплатный NewsAPI Developer-план не предназначен для staging/production.
  [Условия NewsAPI](https://newsapi.org/terms)
- Доступность источников и отсутствие задержки не гарантируются. Условия
  использования выбранных поставщиков нужно учитывать при дальнейшем развитии.

## Локальная проверка

```sh
npm ci --prefix backend
npm ci --prefix frontend
npm test
npm run build
npm start
```

Открыть http://localhost:3001. Это полноценная версия с внешними источниками,
а не статический набор примеров.
