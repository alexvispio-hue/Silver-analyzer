# Проверка Silver Analyzer — 23 октября 2026

Проект переведён на отображение реальных данных. Синтетическая сборка, переключатель
деморежима, demo.json и workflow публикации такой сборки удалены.
Искусственные данные остались только в изолированных автоматических тестах.

## Исправления

- GoldPrice HTTP 403: резервная настоящая котировка Yahoo SI=F с точным обозначением инструмента.
- Привязка WebSocket к localhost: теперь текущий домен /ws и Vite proxy.
- Express раздаёт production-сборку с API и WebSocket на одном порту.
- Параллельные запросы не теряют SQLite-записи и не создают дубли сигналов.
- Неполадки одного API не блокируют остальные панели; ошибки графика видны явно.
- RSI плоского ряда и нулевые значения MACD исправлены.
- История загружается после расчёта текущего сигнала.
- Оценка 24/72ч использует наблюдения около целевого времени, а не сегодняшнюю цену.
- LIMIT ограничен 500 строками; время SQLite трактуется как UTC.
- Зависимости обновлены; npm audit обеих частей показал ноль известных уязвимостей.
- Необоснованные spot open/high/low больше не создаются из двух цен.

## Реальные макроданные и новости

Axios использовал недоступный локальный прокси. Прямой fetch проверен:
существующие ключи FRED и NewsAPI получили HTTP 200. Ключи не выводились и не включены
в исходный код.

FRED теперь использует fetch с таймаутом и резервный публичный CSV. UI показывает
эффективную ставку ФРС, CPI год к году, инфляционные ожидания, безработицу,
изменение занятости и розничных продаж. У каждого значения есть период и ссылка
на исходную серию. Месячная ставка не выдаётся за сегодняшнее решение FOMC.

По умолчанию загружаются реальные Yahoo Finance RSS-новости без ключа.
NewsAPI можно включить конфигурацией при подходящем плане. Сохранены оригинальные
ссылки и даты; пустые, некорректные и удалённые материалы отбрасываются.

Удалены неподтверждённый дефицит 800 тонн, доли стран, фиксированные бычьи факторы,
приблизительный календарь и прогнозы под видом консенсуса. Фундаментальная часть
сигнала теперь интерпретирует наблюдаемое изменение ставки.

## Проверки

- Production-сборка проходит.
- Автотесты проверяют индикаторы, OHLC, fallback цены, конкурентную запись,
  дедупликацию сигналов, отсутствие подмен при сбое источников, 24/72ч,
  FRED CSV, вычисление макропоказателей и RSS-парсинг.
- Сетевой smoke test без обязательных ключей: цена, графики, FRED, новости,
  технический анализ и сигналы отвечают успешно.
- Получены шесть реальных макропоказателей и 18 RSS-новостей при проверке.
- WebSocket и production UI проверены; мобильная компоновка проверена ранее.
- Локальный backend для проверок использует отдельную БД в памяти.
  Пользовательский backend/data.db до работы уже был изменён; он не включается
  в коммит исправлений.

## Оставшиеся ограничения

- XAGUSD spot и SI=F futures не идентичны; история графиков — SI=F.
- Внешние источники могут задерживать данные или блокировать запросы.
- Календарный провайдер пока не подключён.
- Сигналы эвристические, точность не доказана бэктестом.
- Для публичного URL нужен backend-хостинг. Подготовлена конфигурация Render;
  публикация не считается завершённой до проверки выданного URL.
